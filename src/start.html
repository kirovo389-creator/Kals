Чат, терминал, файлы, настоящий Edge-браузер и инструменты разработки игр. Agent Canvas работает напрямую в Windows — Docker и WSL не нужны.

Готов к запуску
Astra использует встроенные Node.js и uv. Первый запуск загрузит Python-компоненты Agent Canvas; потребуется подключение к интернету и место на диске.
